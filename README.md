# Number Guessing Game

A simple Number Guessing Game project where you attempt to figure out what number it is.

## INSTRUCTIONS

#### to activate the session, type this in the commands:

"__guessNum__"

#### TO PLAY:

The game has 3 types of difficulty:<br>
Easy for 10 chances.
Medium for 5 chances.
Hard for 3 chances.<br>

The game asks you to choose any of these difficulties, type the words "Easy", "Medium", or "Hard" to play the game <br>

After choosing any difficulty, start guessing using numbers only.
